The pipeline

Six stops, always in this order. If one fails, the deployment stops there.

  1. GitHubA push to main is the only trigger.
  2. GitHub ActionsA runner checks out the code.
  3. MavenTests run, then the jar is packaged.
  4. DockerThe jar is built into an image.
  5. Docker HubThe image is pushed as latest.
  6. AWS EC2The instance pulls it and restarts the container.

About this project

      
Automated Cloud Deployment is a DevOps project that shows continuous integration and deployment end to end. The app is a small Spring Boot service; the interesting part is everything between a commit and a running container.

      
This page reports what is deployed, how it got there and which tools were involved. Figures marked demo are placeholders.
