The pipeline

Six main stages take the code from GitHub to the cloud.

  1. GitHub A push to main starts the workflow.
  2. GitHub Actions A runner checks out the code.
  3. Maven Tests run and the application is packaged.
  4. Docker The application is built into an image.
  5. Docker Hub The image is uploaded to the registry.
  6. AWS EC2 The instance pulls the image and runs the container.

About this project

Automated Cloud Deployment is a DevOps project that demonstrates continuous integration and continuous deployment. When code is pushed to GitHub, GitHub Actions tests and builds the application, creates a Docker image, uploads it to Docker Hub and deploys it to AWS EC2.

The dashboard presents the deployment process, environment information, workflow history and an example deployment log.
